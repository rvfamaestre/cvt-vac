# Line-following robot

Our CentraleSupélec robot project: follow a line, detect intersections and avoid obstacles. Python, OpenCV and Arduino, with a Simulink model.

By Rafael Maestre López, Gabriel Sylvestre Núñez, Matthieu Giraud-Sauveur, Loïc Perthuis and Lûqman Proietti (Ctrl + Car).
